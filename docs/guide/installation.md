# Installation

Install the package and its peer dependency:

```bash
npm install @lightweight-charts-pro/vue3 lightweight-charts
```

## Requirements

- Vue 3.4+
- Node.js 18+
- TypeScript 5.x (optional)

## Import

```typescript
import {
  LightweightChart,
  CandlestickSeries,
  LineSeries,
} from '@lightweight-charts-pro/vue3';
```
